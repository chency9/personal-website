## Modern Web Guidance 的应用

- **motion**：遵循 “Provide a pause mechanism”，提供可见、可由键盘操作的动画暂停按钮；遵循 “Keep the final state”，减少动态效果时保留完整内容和交互反馈。
- **accessibility**：遵循 “Use the native `<dialog>` element”，用 `showModal()` 管理模态、焦点与页面外部的 inert 状态，避免手写焦点陷阱。遵循 “Don't use placeholders as primary labels”，所有实验控件使用明确标签。
